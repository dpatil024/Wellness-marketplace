Applied rules

Where each inspiration takeaway lands in the tokens
Patreon
Tier cards live directly under the bio — a layout rule for the creator profile, not a token: bio → tiers, nothing between them.
Cameo
--color-accent-* is the only color used for a primary CTA. One accent action per screen, no competing buttons.
Noom / Ro
Scope-of-practice copy sits in --text-sm / neutral-600, placed immediately above the subscribe button — never a footer or modal.
Whoop / Oura
--text-metric-hero appears once per dashboard view. Supporting numbers use --text-metric-secondary or smaller.
